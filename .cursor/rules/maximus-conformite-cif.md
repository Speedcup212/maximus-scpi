# MaximusSCPI — Conformité CIF / AMF

## Contexte réglementaire

MaximusSCPI est opéré par un **Conseiller en Gestion de Patrimoine (CGP)** inscrit **ORIAS**, soumis à la réglementation **MIF2** et aux règles de l'**AMF**.

Toute production (texte, code, data, template) doit respecter ces contraintes.

## Formulations interdites

Ne jamais utiliser, même implicitement :

| Interdit | Raison |
|---|---|
| « rendement garanti » | Promesse de performance |
| « sans risque » | Minimisation du risque |
| « meilleure SCPI pour vous » | Recommandation personnalisée automatisée |
| « recommandation personnalisée » (sans négation) | Hors périmètre sans recueil patrimonial |
| « portefeuille conseillé » | Conseil personnalisé |
| « allocation recommandée » | Conseil personnalisé |
| « sélection adaptée » | Conseil personnalisée |
| « performance exceptionnelle » (sans contexte) | Allégation non vérifiable |
| Taux de distribution présenté comme futur | Données historiques uniquement |

## Formulations autorisées

| Autorisé | Usage |
|---|---|
| « simulation pédagogique » | Quiz, simulateurs |
| « pré-orientation » | Résultats quiz |
| « critères à approfondir » | Analyse SCPI |
| « allocation théorique indicative » | Répartitions sectorielles/géographiques |
| « ne constitue pas une recommandation personnalisée au sens MIF2 » | Mention légale obligatoire |
| « données historiques » | Taux de distribution passés |
| « à valider avec un conseiller » | CTA humain |

## Rappels obligatoires

- Les **taux de distribution** sont des **données historiques**, jamais des promesses.
- Les **revenus SCPI ne sont pas garantis**.
- La **liquidité SCPI est limitée** — toujours le rappeler si des chiffres de performance sont cités.
- Les **risques SCPI** (perte en capital, vacance, endettement) doivent être mentionnés quand des performances sont affichées.
- Les **données SCPI** doivent être sourcées (DIC, bulletin, rapport annuel, ASPIM).

## CTA et parcours

- Les CTA de conversion doivent envoyer vers un **échange humain** (Calendly) ou le **comparateur pédagogique**.
- Pas de tunnel de souscription automatisé sans validation conseiller.
- Le quiz homepage produit une **pré-orientation**, pas un conseil.

## Contrôle avant publication

L'agent `CONFORMITE_AGENT.md` doit relire toute formulation sensible avant déploiement.
