
---

## Étape 1 — Diagnostic (lecture seule)

Fichiers à consulter (max 5, lister avant d'ouvrir) :
- [ ] Page ou composant cible
- [ ] `src/components/SEOHead.tsx` si balises méta concernées
- [ ] Fichier data associé si contenu SCPI
- [ ] `AUDIT_SEO_COMPLET_MAXIMUSSCPI.md` si audit global existant
- [ ] Autre : ___

Attendre validation avant ouverture.

---

## Étape 2 — Livrable attendu

Choisir le type :
- [ ] Plan de mots-clés (volume / difficulté / intention)
- [ ] Brief article (H1 / H2 / angle / longueur / CTA)
- [ ] Méta-description + titre SEO
- [ ] Recommandation de maillage interne
- [ ] Audit éditorial SEO

---

## Étape 3 — Conformité obligatoire

- [ ] Pas de promesse de rendement dans les titres ou accroches
- [ ] Mention risques présente si chiffres SCPI cités
- [ ] Distinction information générale / pédagogie / conseil personnalisé
- [ ] Aucune formulation type "meilleure SCPI" sans réserve
- [ ] Renvoi vers DIC / note d'information si pertinent
