## Étape 2 — Checklist RGPD + CIF obligatoire

### RGPD
- [ ] Consentement préalable explicite présent
- [ ] Lien de désinscription inclus dans chaque email
- [ ] Base légale identifiée (consentement / intérêt légitime / contrat)
- [ ] Minimisation des données (collecter uniquement le nécessaire)
- [ ] Durée de conservation définie (max 3 ans)

### CIF
- [ ] Pas de promesse de rendement dans les emails
- [ ] Pas de recommandation personnalisée sans recueil d'informations
- [ ] Pas de pression commerciale ni d'urgence artificielle
- [ ] Distinction claire email pédagogique / prise de contact conseil
